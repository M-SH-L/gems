# Gems V2 — 3D world

V2 is a separate, fully 3D version of Gems built with **three.js**. It lives
alongside V1: the app still opens on the V1 desktop, and a swirling portal orb
(bottom-right of the desktop) pulls you through into V2. V2 has no theme
switching; it has one look of its own.

## Getting there and back

| From | How |
|------|-----|
| V1 → V2 | Click the **ENTER V2** portal orb. The desktop spirals into a vortex that opens from the orb. |
| V2 → V1 | **Back to V1** button in the hub, or **Esc** in the hub. The portal runs in reverse with V1 colours. |
| Direct link | `/#v2` opens straight into V2; clearing the hash (or using the Back button) returns to V1. |

The portal (`src/portal/`) is a small raw-WebGL shader, not three.js, so V1
doesn't load the 3D bundle. `V2App` is lazy-loaded and starts downloading the
moment the portal opens. If the V2 chunk fails to load, you land back in V1. If
WebGL is unavailable, V2 shows a "3D unavailable" panel with a way back.

## The hub

A floating island in space with three pedestals, each holding a gem for one
game. The carousel turns to bring the selected gem forward.

- **← / →** (or A / D), the ◀ ▶ buttons, or the dots: browse
- **Enter / Space**, **Play**, or clicking the front gem: fly into the gem and launch the game
- Clicking a side gem selects it

## The games

The three games use different genres and different controls.

### Gem Rush: endless runner
Roll down a three-lane synthwave causeway. Crystal walls block lanes and
low laser bars must be jumped. Every row leaves at least one lane open. Gems
add 25 points each, and speed ramps up over time.

- **← → / A D**: switch lane. **Space / ↑ / W**: jump. **R**: restart
- Touch: tap the left or right third to switch lanes, tap the centre to jump

### Sky Stack: timing stacker
Slabs slide in, alternating between the X and Z axes. Drop each one on the
tower. Any overhang is sliced off and tumbles away, and missing the tower
completely ends the run. Near-perfect drops (within 0.1 units) snap into place,
and three perfects in a row start growing the slab back.

- **Space / Enter / click / tap**: drop. **R**: restart

### Tilt Maze: physics puzzle
Tilt a floating board to roll a marble to the glowing pad across five
hand-built levels, avoiding the holes. Bonus gems are optional. Best times are
saved per level.

- **Arrows / WASD**: tilt. **Drag** (mouse or touch): tilt proportionally. **R**: restart level

Best scores and times are stored in `localStorage` under `gems-v2:*`.

## Architecture

```
src/
├── portal/                 # V1 ↔ V2 transition (no three.js)
│   ├── PortalOrb.tsx       # the doorway on the V1 desktop
│   ├── PortalTransition.tsx# timeline: open → swap worlds → flash & fade
│   ├── PortalContext.ts    # lets V1 components open the portal
│   └── vortex.ts           # raw WebGL swirl shader
└── v2/
    ├── V2App.tsx           # owns the single WebGL Stage + Input, routes screens
    ├── registry.ts         # game metadata (name, colour, controls)
    ├── core/
    │   ├── Stage.ts        # renderer, resize, frame loop; scenes are swapped in
    │   ├── input.ts        # keyboard → actions (left/right/jump/confirm/back/…)
    │   ├── env.ts          # sky, stars, lights, gem helpers, seeded RNG, disposal
    │   ├── fx.ts           # pooled particle bursts
    │   └── storage.ts      # safe localStorage wrappers
    ├── hub/HubScene.ts     # 3D game picker
    ├── games/
    │   ├── runner/  logic.ts + RunnerScene.ts
    │   ├── stacker/ logic.ts + StackerScene.ts
    │   └── maze/    levels.ts + logic.ts + MazeScene.ts
    └── ui/                 # React HUD overlays per screen
```

Each game keeps its rules in a pure `logic.ts` with no three.js or DOM
dependencies, so the rules are unit-tested directly
(`src/__tests__/unit/v2*.test.ts`). The `*Scene.ts` classes render that state
and forward input. React only draws the HUD and receives throttled HUD updates.
All screens share one WebGL context, and a scene is disposed when its screen
unmounts.
